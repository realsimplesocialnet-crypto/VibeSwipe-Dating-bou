Myage

Let’s get Myage open.

You can use the website in your browser without installing the app.

Open Myage website

Seeing “Myage requires Chrome”?

That message comes from Android’s installed website launcher, before Myage can load. It can appear even when Chrome is installed. This page cannot change that launcher’s browser binding.

  1. Open the Myage website directly in a working browser first, and check that you can sign in.
  2. If the old home-screen installation still fails, replace that installation using the browser’s Install app or Add to Home screen menu.
  3. You can use another supporting browser, such as Samsung Internet. Keep the browser used for installation enabled in the same phone profile.

Before replacing the installation: save any unsent drafts and make sure you know your sign-in details. Do not delete your Myage account or clear browser/site data; replacing the installation may require signing in again.

Slow connection or a blank page?

Check your connection, then open the website again. Installation is optional; there is no Chrome-only check on the website.

A website app still needs a supporting browser. Opening it without any browser requires a separate native Android app.
