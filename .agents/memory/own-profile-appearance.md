description: Approved visual direction for the signed-in user's Profile tab.
---

The user approved applying the generated pink-to-peach profile mockup to the Profile tab: a large circular portrait overlapping a white rounded card, centered identity and location, a prominent pink Edit profile button, and about/work sections.

Their later refinement asks for a clean light-pink My Profile screen with a gear-labelled Settings button at the top right and clear About, Work, Hobbies and Photos sections. Keep the fixed bottom navigation with Profile highlighted.

My Profile must fit on one screen without vertical scrolling. Use compact previews for long content, with full details available through Edit profile; keep the photo, identity, Settings, Edit profile, and all four section previews above the fixed navigation.

My Profile must not show the top logo/branding header. Start with the My Profile title and Settings, leaving more room for the user's pictures. Bottom tabs should blend into the profile background, not form a dark strip that covers the photos.

**Why:** The user explicitly selected “Apply to the Profile tab” after reviewing the mockup, then supplied the more specific layout and repeatedly emphasized that everything must fit without scrolling.

**How to apply:** Use this direction for the user's own profile overview, populated with actual account details. This approval is not a request to change other people's full-profile views or the Edit Profile form.
