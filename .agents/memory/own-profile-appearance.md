Profiles should use the black-and-white MyAgeBeauty visual direction. Show the member's real main photo as a circle, keep the name separate from age, and place age in About. Keep real profile details, follower counts, and the member's media grid; use no sample identity or copied counts.

Keep sections unboxed with spacing rather than card borders. Preserve Settings, profile editing, referral tools, and the Reels/Reposts/Saved/Likes gallery; content that does not fit the reference's first screen can remain below the fold. Do not add a product logo to the signed-in profile.

Show follower and following counts with prominent black-or-white numbers and smaller labels. Use rose-red for Follow and Like action buttons, not for the count numbers. Keep the fixed bottom navigation blended into the page background.

**Why:** The user asked to match their profile references, specified MyAgeBeauty's black-and-white palette, and clarified that only Follow and Like buttons should use the rose-red accent.

**How to apply:** Keep own and public profiles consistent across Android and web, preserve each member's data and actions, and treat screenshots as layout references rather than permission to replace content.
