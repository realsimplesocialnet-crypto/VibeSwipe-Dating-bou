name: Own-profile appearance
description: Approved visual direction for the signed-in user's Profile tab.
---

Profiles should use the black-and-white MyAgeBeauty visual direction. Show one real main profile photo as a circle, keep the name separate from age, and place age in About. Show Matches, Followers, and Following counts. Keep real profile details and use no sample identity or copied counts.

Keep sections unboxed with spacing rather than card borders. Do not repeat profile photos in a gallery; the profile picture appears once, and the profile media area shows posted Reels. Preserve Settings, profile editing, and referral tools. Keep Reels first, with Saved and Likes separate; do not add Reposts. Do not add a product logo to the signed-in profile.

Show Matches, Followers, and Following with prominent black-or-white numbers and smaller labels. Use rose-red for Follow and Like action buttons, not for the count numbers. Keep the fixed bottom navigation blended into the page background.

**Why:** The user asked to match their profile references, specified MyAgeBeauty's black-and-white palette, clarified that only Follow and Like buttons should use the rose-red accent, and asked for one profile picture with Reels as the profile media.

**How to apply:** Keep own and public profiles consistent across Android and web. Show only the first profile photo in the UI and avoid deleting older stored photos unless the user explicitly requests permanent deletion. Treat screenshots as layout references rather than permission to replace member content.
