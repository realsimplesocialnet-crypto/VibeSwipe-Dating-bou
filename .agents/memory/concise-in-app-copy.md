---
name: Concise in-app copy
description: The user's preference for minimal text on VibeSwipe's signed-in screens.
---

Keep signed-in screens focused on functional labels and controls. Do not show success messages that narrate ordinary user actions (such as liking or saving); retain errors and essential safety, privacy, or consent text.

**Why:** The user has repeatedly asked to remove extra text and visual clutter from the signed-in app.

**How to apply:** Keep routine success feedback in the control state itself. Show a message only for errors or essential privacy, safety, and consent needs.
