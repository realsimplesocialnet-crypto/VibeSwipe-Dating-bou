---
name: Concise in-app copy
description: The user's preference for minimal text on VibeSwipe's signed-in screens.
---

Keep signed-in screens focused on functional labels, controls, and essential status. Avoid taglines and paragraphs explaining how a feature works.

**Why:** The user has repeatedly asked to remove extra text and visual clutter from the signed-in app.

**How to apply:** Keep interface copy brief. Retain error, privacy, safety, and consent text when it is needed to complete an action clearly or safely.
